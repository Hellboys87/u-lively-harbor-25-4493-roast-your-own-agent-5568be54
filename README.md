One line, one roast, no mercy. My agent searched the codebase, found nothing, said sorry — and then cited the file it had just proved doesn't exist. With sources. The joke is the contradiction: an apology followed by the exact same failure, delivered with total confidence — and then a second twist, fake evidence for a phantom file.

The roast line (123 characters):

> My agent searched the codebase, found nothing, said sorry, then cited the file it just proved doesn't exist — with sources.

The judge is an LLM: it scores how hard the line roasts the entrant's own agent, how fresh and funny it is, and how specific it is to real agent behaviour — confident wrong answers, endless caveats, eager agreement, tool calls that go nowhere.

## Run it

```sh
node main.ts
```

This writes the single roast line (no trailing newline) to `/output/entry.txt`.
